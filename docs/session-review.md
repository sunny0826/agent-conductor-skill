# 会话归档复盘

按「归档日」复盘会话时，先确定归档时间，不按最后活动时间。`lody_session_list` 没有 `archivedAt` 字段；用 `updatedAfter` 得到的是活动时间，活动在归档前一天、归档在当天的会话会被漏掉。

## 选取范围

```bash
mise exec -- node tools/archived-sessions.mjs --date 2026-10-21
```

工具读取本机 `~/.lody/logs` 中 `Archived session runtime released` 事件，按 `Asia/Shanghai` 过滤归档日。加 `--json` 输出机器可读结果，`--log-root` 可换日志目录。

- 只覆盖本机日志。其他机器上归档的会话不在本机日志里；用 `lody session list --archived` 的“当日活动 + 当前已归档”代理口径补查，并在索引里标注“归档时间未验证”。
- 归档日志可能因轮转在 gzip 流中间截断；工具保留已读出的行，不因单个文件失败放弃全部结果。
- 在当天 inventory 记录每个会话的归档时间、时间来源和机器；代理口径与真实归档时间分开写。
