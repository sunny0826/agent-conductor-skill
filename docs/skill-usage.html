给执行 Agent 的接口说明

全量发现使用 lody_machine_list、lody_agent_config_list、lody_agent_role_list，并跟随 nextCursor 到结束。lody_session_create_options 最多给 20 个稀疏候选，适合取得当前上下文及解析项目。


按角色派发传 agentRoleId，角色目录行决定机器、模型、推理和权限；显式组合传 machineId、agentConfigId、modelId，选项来自对应 runConfig。权限须符合已有授权。


lody_session_create 使用调用方生成的 operationId 启动异步任务，完成后自动续接，避免轮询 operation_get。需要独立项目上下文时传 workContext；它与 useCurrentSessionAsParent 互斥。实际字段以当次工具说明为准。


本指南核对了当前 Lody 工具说明；本次没有扫描模型、写入角色配置或启动子 Agent。








完成意味着什么


    

  • 写清目标、范围、可观察的完成条件和已有证据。预算或模型有要求时明确写出。
    • 

  • 调查、设计和审查各有交付范围。要实施时明确要求实施；人工评审关口写进提示。
    • 

  • 编译、审查和实际验收证明不同事情。未执行的功能保留为未验证。
    • 

  • 技能不会赋予宿主缺少的委派、后台或定时能力。持续任务需要真实活动句柄和停止条件。
    • 

  • 提交、推送、合并、发布及对外发送沿用实际授权。原则技能用于改变具体判断，按需读取。
