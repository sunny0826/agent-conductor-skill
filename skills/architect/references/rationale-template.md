# 设计记录

按任务规模选用下列内容，用实际事实替代说明；不需要复制固定栏目。调用者用法先于类型草图。

- **问题与约束**：要改变的行为、现状证据、必须保留的调用者与不变量、版本和授权范围。
- **调用者用法**：入口、输入、结果、错误、异步或清理方式；示例与签名一致。
- **结构**：核心数据、状态拥有者、公共签名、模块边界、数据路径、校验位置与未实现部分。说明接口为调用者隐藏及暴露的复杂度。
- **方案比较与选择**：结构上不同的备选、可行性证据、选定基础方案、吸收和拒绝的部分及理由。注明候选来源、独立性、失败项；不按模型票数选方案。
- **接受的取舍**：当前范围为何值得承担该成本，迁移与维护者需要知道什么。
- **未知和风险**：区分可实验确认的事实、需要用户决定的偏好，以及运行条件缺口。
- **实施与验证**：若已授权，给出第一个可验证单元、实际完成与偏离、命令和结果；设计任务仅描述建议步骤，不声称已实施。
