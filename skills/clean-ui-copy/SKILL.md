# 清理防御性 UI 文案

本技能用于清理界面中“非操作引导、非报错、以防误解/免责/口径限定/实现细节辩解为主”的文案噪声，同时守住真正影响操作预期与读数理解的最小信息，不因清理把界面删成信息黑洞。

## 适用边界

- **纳入**：主视图常显免责与解释段落、冗余页眉/卡片/表格副标题、泄漏到界面的内部实现细节或仓库相对路径、与主标题语义重复的装饰性 Eyebrow/Overline、不合受众的生硬造词与多余括号尾注，以及被这些文案锁死的单测/UI 测试与伴生死常量。详细分类见 [UI 文案排查与复核清单](references/copy-audit-checklist.md)。
- **不纳入**：视觉改版、组件库选型或布局重构（不顺手重做样式系统）；文档/报告/PR 润色（若已安装，用 `unslop`）；工程门禁、强哈希、CI 与文档隐形锁减负（用 `fkgpt6`）；局部源码与注释清理（用 `rigor` 代码检查）。
- **权限边界**：排查与分布统计只读；批量删改前先交付盘点表和裁决方案等用户确认；不自动 commit、push、合并 PR 或改写无关交互逻辑。

## 执行流程

1. **全展示面只读盘点**
   按 [UI 文案排查与复核清单](references/copy-audit-checklist.md) 扫描目标界面的全部文案来源，不只看主页面文件，同时覆盖：主视图常显文案、条件显/折叠区/弹窗、状态枚举与词表常量、无障碍描述（`aria` / `Description`）以及预览/调试模式字符串。

   输出**逐页分布总览表**（页面/模块 · 总数 · 常显数 · 条件/折叠数 · 密度判断）和逐项位置清单，准确统计实测条目数，不估算。

2. **四级裁决与停等确认**
   对每条命中项给出明确去向，而非“一刀切全删”：
   - **直接删除**：纯免责套话、重复解释、无信息量的装饰性 Eyebrow/Overline、面向终端用户无意义的源码相对路径、已由界面结构或邻近标签表达清楚的废话。
   - **收进折叠区 / Tooltip / 次级入口**：确实必要但不需要常驻主视图的背景说明（如必填配置格式示例、复杂统计口径）。
   - **压缩为极短数据标签**：删掉会导致用户把正常数值误判为 Bug 的关键口径（如多核百分比可超过 100%、小样本量提示），用极短副标题或纯数据后缀替代整句免责。
   - **保留**：真实操作预期（解释“保存后为什么还需下一步”等行为边界）、可执行报错与恢复指引、不可逆操作/权限/隐私/计费确认以及真实法律合规声明。

   **默认停在盘点与裁决表**，等用户确认范围和保留边界后再动手修改。

3. **清理实施、死代码收敛与测试松绑**
   - 按确认后的裁决修改界面文案，同时清理生硬造词与过度口语化表达，使文案长短与目标受众和场景匹配。
   - 删除辅助文案函数、分支或词表条目后，同步清理随之产生的**未读参数、未引用常量与死 helper**，检查空列表/空状态拼接（防止删完文案后渲染出 `[]` 或多余分隔符）。
   - 更新断言旧防御文案全文的单测与 UI 测试，改为断言核心数据、状态与结构，不把新文案再次逐字锁死。

4. **删后防误删与残余复核（必须执行）**
   - **防删过头**：逐条核对删除项，确认未误删决定用户能否看懂数值的关键口径或解释下一步动作的操作预期；若误删，还原为短标签或默认收起的折叠块。
   - **防信息断链**：若界面指向外部或产品文档，核实目标文档真实包含对应说明；不得在桌面/客户端界面直接展示仓库内部相对路径。
   - **防残余与定义源漂移**：复查状态枚举、表格单元格、无障碍描述及指标定义源文档，确认无漏网防御腔或代码与文档口径矛盾。
   - **运行检查与真实界面抽查**：运行项目编译、静态检查与相关测试（确认无未读参数/未引用常量报错）；若具备真实界面运行能力（可按需配合 `control-ui`），抽查重灾区页面确认视觉层级清晰且无空洞留白，未实跑界面则明确标注“未实跑 UI”。

5. **交付结果**
   汇报清理统计（按四级裁决分类计数）、松绑的测试与清理的伴生死代码、删后复核发现与修正、实际通过的检查命令及未验证范围。
