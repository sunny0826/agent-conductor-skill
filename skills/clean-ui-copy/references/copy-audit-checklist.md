# UI 文案排查与复核清单

本清单配合主说明，用于全展示面盘点防御性/冗余 UI 文案、执行四级裁决，并在清理后复核是否误删关键口径或遗留残余。

---

## 一、五类高频防御性 / 冗余 UI 文案信号

1. **免责与反证套话**
   - 例如“仅反映本次实测记录，不代表其他场景”“不构成综合评分”“样本较少，仅供观察”“核验通过不代表……”“各次分别展示，不合并成绩”等反复向用户打补丁、强调系统局限的句子。
2. **实现边界与内部路径泄漏**
   - 在界面上解释“没有逐单位事件源因此未测……”“缺测不补零、分母不缩”“不会向外部发送请求”等内部实现策略，或直接把 `docs/xxx.md`、`cli/docs/...` 等源码仓库相对路径渲染给桌面/Web 终端用户。
3. **重复说明与装饰性 Eyebrow / Overline**
   - 在主标题上方习惯性放置英文大写眉题，且语义与主标题重复、只起装饰作用；或在页眉、卡片、表格底部反复复述按钮名称与列表列义的副标题/页脚。
4. **生硬造词与冗余尾注**
   - 不符合当前界面受众的内部缩写或造词、生硬口语化动词，以及在列表项、状态徽章或表单项后反复追加括注免责。
5. **残余死文案与边界拼接瑕疵**
   - 隐藏在次级状态枚举、无障碍描述（`aria` / `Description`）和预览调试字符串里的漏网防御腔；以及清理文案后暴露出来的未读函数参数、全仓零引用文案常量、空数组拼接 `[]` 或孤立分隔符 `·`。

---

## 二、全展示面盘点范围

只搜页面主文件容易遗漏大量文案，盘点时必须逐一检查以下 5 类来源：

- **主视图常显文案**：页眉副标题、KPI/指标卡片底部说明、图表顶部说明、表格页脚、设置卡片常显说明。
- **条件显 / 折叠区 / 弹窗**：空状态、小样本提示、取消/删除确认弹窗、已收进折叠区的详细口径。
- **状态枚举与共享词表常量**：集中定义状态文本、表格列描述或公共文案标签的文件。
- **无障碍属性与屏幕阅读器描述**：`aria-label`、`aria-description`、控件 `Description` 等容易残留长段防御文案的字段。
- **预览 / 调试模式文案**：仅在 UI 调试、预览分支或模拟数据里出现的说明文本。

## 三、四级裁决速查表

| 裁决级别 | 判断标准 | 典型处置 | 对比示例 |
| --- | --- | --- | --- |
| **直接删除** | 删掉后不影响操作预期、不导致误读正常数据，纯属重复或防误解免责 | 直接移除对应文本及渲染分支，释放主视图呼吸感 | 删除“仅反映本次实测，不代表其他场景”“— 表示缺测”等套话；删除与主标题同义的装饰性 Eyebrow |
| **收进折叠区 / 次级入口** | 属于必要配置规则或详细统计定义，但不应常驻主视图 | 放入默认收起的折叠块、帮助 Popover 或已有说明入口 | 将长段配置格式字段说明（如 JSON schema 示例）与详细指标计算定义收进默认折叠区 |
| **压缩为极短数据标签** | 删掉会让人把正常现象误判为系统 Bug，必须保留关键口径 | 改为极简副标题或纯数值后缀，去掉防御语气 | “1 个逻辑核 = 100%，可超 100%，不含子进程” → `单核 100% · 仅主进程`；小样本长句提示 → 纯数据后缀 `（n=24）` |
| **保留** | 说明操作后真实行为边界、可执行报错、不可逆风险或合规要求 | 原样保留或精简为直接一句，不作为防御废话误删 | **保留操作预期**：“保存不会自动创建目录；保存后点击「准备环境」创建”（解释保存后状态为何仍显示目录不存在） |

## 四、删后防误删与工程收口清单

清理完成后必须逐项自检：

1. **关键读数口径复核**
   - 对被删文案逐条反问：用户看到 `600%` CPU、实际 token 与预设档位不同或局部极小样本统计时，界面上是否还有最简口径避免误解？
2. **操作预期复核**
   - 删掉表单/设置页说明后，用户保存或提交完能否理解系统为什么没有立即执行某动作、下一步该去哪里触发？
3. **指引闭环与路径核验**
   - 界面文案、链接或按钮指向的产品帮助文档确实包含对应说明；不得在安装包/客户端界面展示源码仓库内部相对路径。
4. **伴生死代码与拼接边界清理**
   - 全仓检查因删除文案分支产生的未读函数参数、未引用词汇常量和无用 helper；确认列表或局限性字段为空时不会拼接出 `[]`、空括号或孤立 `·`。
5. **测试松绑与静态检查**
   - 修改断言旧免责文案全文的单测/UI 测试，改为断言真实数值、状态切换和组件结构，不锁死新文案；实跑构建、类型检查、单测与项目 lint 确认零新增告警。
6. **文档定义源一致性**
   - 若清理过程中去掉了 UI 侧的条件提示（如特定样本区间标记），同步核对指标或产品定义文档，防止文档要求与 UI 实现互相矛盾。
