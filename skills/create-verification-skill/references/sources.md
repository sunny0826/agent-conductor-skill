# 适配

本版包含项目事实、生成步骤、实际运行、清理后保留证据，以及地图索引、功能与入口、动作和结果、跳过记录。运行时无需安装其他技能。

适配取舍：

- 删除 Cursor 专属 `disable-model-invocation`，保留默认自动选择；技能能否被发现仍取决于实际安装位置和宿主能力。
- 将固定 `.cursor/skills` 落点改为核对项目与宿主发现约定；无自动发现能力时明确使用文件引用。
- 保留启动、健康/身份检查、真实驱动、证据和隔离规则；区分生成说明的一次实跑与日常整体验收。
- 生成器独立可用，不包含模型目录、角色参数或 setup 配置协议。conductor 负责按需调用与判断交付。
- 生成后的修订写在本技能内，不把另一个维护技能设为生成前置条件。
- 以当前用户授权和宿主规则限制外部副作用；纯解释、只读审查及一次性小修改不强制生成。
