# 解释指引

主 AI 直接调查或汇总探索材料时使用。

- 先回答原问题，让读者知道系统做什么、主要入口在哪里。
- 用必要的概念解释完整路径：谁接收输入、调用什么、数据如何变化、谁拥有状态、何时结束、错误如何传递。
- 合并重复发现。关键连接与冲突回到源码核对；某个角度失败时保留缺口，不补造连线。
- 给出接手者需要的文件与符号定位，关键事实引用当前版本的行号。不堆砌全部阅读记录或大段代码。
- 多组件流程用简图帮助理解；文字与图遵守同一证据边界，未知连接明确标出。
- 模块位置建议与当前结构分开。历史原因需引用历史材料；只有现状源码时解释机制，不声称知道作者动机。
- 按问题采用概览、关键概念、运行流程、文件位置、陷阱等内容，省略不适用项。保留范围、版本、未验证项及运行证据位置。
