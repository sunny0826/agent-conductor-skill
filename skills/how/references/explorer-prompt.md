# 探索请求

仅在确需委派时填实后使用；不要求固定数量或特定工具名。

> 请从源码独立追踪指定角度，只读调查，不修改产品或配置，不驱动共享应用。只使用所授予的读取和执行权限。
>
> 原问题：填写用户要理解的行为。
>
> 范围与版本：填写项目、入口、基线、相关未提交内容及可读取边界。
>
> 探索角度：填写本任务负责的入口、数据、状态或边界；不重复其他角度。
>
> 权限：填写实际宿主限制；若未授权运行，只做静态追踪。提示词只读不等于系统已强制沙箱。
>
> 从入口沿注册、分派和调用追到结果，读取真实实现。核对关键类型、输入转换、分支、异步、错误及状态归属。引用文件、符号和行号；无法追通时说明止步位置。
>
> 返回简明事实包：核心组件、调用与数据流、状态拥有者、边界、阅读清单、非显然事实、未知项。将运行观察与静态推导分开；有运行时附完整命令与退出码。不要猜测历史动机或输出秘密。
