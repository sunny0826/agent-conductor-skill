# 适配

| 文件 | 保留与适配 |
|---|---|
| [SKILL.md](../SKILL.md) | 简单问题直接解释，复杂问题分角度探索再汇总；交付可用运行模型。 |
| [explorer-prompt.md](explorer-prompt.md) | 入口、调用链、数据、结构、边界、阅读清单与未知项。 |
| [explainer-prompt.md](explainer-prompt.md) | 核对矛盾、合并证据、简洁概念模型与按需流程图。 |

移除 Cursor 路径、Task 专属字段、固定模型及自动模型回退。简单问题改由主 AI 完成；复杂问题在权限与能力允许时委派，否则串行取证，不将模型目录扫描设为解释前置条件。复用已有模型选择，不扩展 setup v2。

移除显式调用限制，保留默认自动选择。主 AI 对最终解释负责，关键路径亲自核对，不照搬探索者报告。补充版本、读取范围、权限、运行证据分层及状态归属；历史动机必须有历史证据，机制解释不代替验收、影响分析或设计。

独立包自包含，配套 conductor 仅在用户要求解释机制、归属或实施确需澄清系统时按需调用。
