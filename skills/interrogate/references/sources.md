| 内容 | 保留与适配 |
|---|---|
| [SKILL.md](../SKILL.md) | 范围、意图、同一证据包与独立模型、主审裁决。改为跨宿主能力发现与诚实降级。 |
| [reviewer-prompt.md](reviewer-prompt.md) | 具体位置、证据、可选建议及合法零发现；增加权限与快照说明。 |

| 主审裁决 | 过滤误报、确认真实调用路径、保留四类裁决；共识不等于证明，不限制真实发现数量。 |
| [lead-judgment.md](lead-judgment.md) | 过滤风格填充、不可达假设、过早抽象和换写法偏好。不引入固定模型或人数门槛。 |

删除宿主专属路径与 Task 字段、默认模型表、自动开 PR 和显式调用限制，保留正常自动发现。配置复用实际可用 setup，不另建协议；当前 v2 单 reviewer 不扩展 schema。模型名单与失败状态属于本轮事实。补充未提交变更、快照漂移、最小授权证明和原始报告追溯。

独立使用只需实际宿主能力，无需安装其他技能才能理解审核流程。配套使用时，setup 管配置，conductor 管调度，interrogate 管审核裁决，blast-radius 管影响证明，verify 管功能验收。
