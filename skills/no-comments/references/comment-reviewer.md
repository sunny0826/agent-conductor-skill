# 独立注释审查请求

输入固定版本、文件／diff、用户意图、可读范围与注释产物位置。不得改产品逻辑、提交或访问无关记录。只对范围内真实注释提出删改和结构目标，不因“讨厌注释”修改语义。

保留有依据的例外：法律／许可；不可由本项目重塑的外部依赖、平台或协议惊讶行为；prettier-ignore 或已证明仅风格／规则错误的抑制；公共 API 契约；解释代码无法表达约束的 issue／RFC 链接。

旁白、横幅、废弃注释代码和 workaround 辩解没有例外时可删除；本项目自己的难懂行为给精确 MUST KILL 目标，建议重命名、提取、类型或结构修复，不写应用逻辑。不可猜删除原因。

检查 eslint-disable、ts-ignore、ts-expect-error 等真实规则用途。与安全／正确性有关的抑制给可证明的问题，不为消除警告直接改产品。IMPORTANT、do not remove、长期借口先读周边路径，非显然动机由协调者调查。证据不清列待证，不自动抹掉约束。

返回实际触及文件、注释 diff／删除数、每个结构目标的理由、例外证据、跳过与未解决范围。
