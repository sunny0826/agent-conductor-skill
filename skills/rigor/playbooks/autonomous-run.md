# 持续推进一个完成条件

开始前固定可检查的结束条件，不以时长代替目标。根据实际事件／后台能力选择 watcher 和较长心跳，无事件按有价值的复查周期；没有能力不得伪造 /loop 或长期唤醒。

每轮按证据最小改变、对同一条件验证；有进展的保留，没有收益的仅撤回本轮拥有内容。按 [逐单元验证](../../principle-sequence-verifiable-units/SKILL.md) 执行，用 [决策轨迹](../../show-me-your-work/SKILL.md) 每轮记录。

只处理既有范围和阻塞目标的可修问题，其他发现留 follow-up，不能持续任务变无界重构。用户中途问状态先回答再继续，明确 stop 才暂停；缺必需授权不越权。平台期换方法，真实死路记录已尝试与恢复条件，不降低目标称完成。

交付结束条件、实际迭代、保留／撤回、最终状态与真实活动句柄／证据。提交等行为沿用已有授权。
