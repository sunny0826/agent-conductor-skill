# 范围内代码检查

这是原模式第三方代码清理入口的包内替代，不要求安装其他插件。核对 diff 与真实源码：删除本轮冗余、重复状态、无调用者包装、无依据保护分支和遗留入口；不为整洁强行重构或删除未知契约。类型、生命周期、并发、持久化和外部边界按具体触发路径核实。

检查用户改动与无关文件未被覆盖、依赖与锁定来源一致、所有真实消费者同步、测试能观测行为、错误传播不被吞掉。重复补丁先查根因，未证明风险不要凭个人风格设阻塞。注释问题用包内 [no-comments](../../no-comments/SKILL.md)，跨边界风险用 [blast-radius](../../blast-radius/SKILL.md)，需要独立审查时使用 [interrogate](../../interrogate/SKILL.md)。

保留删除和保留的依据、范围与未验证项。检查不授予提交、外部评审回复或批量修复权限。
