# 范围内代码检查

这是原模式第三方代码清理入口的包内替代，不要求安装其他插件。核对 diff 与真实源码：删除本轮冗余、重复状态、无调用者包装、无依据保护分支和遗留入口；不为整洁强行重构或删除未知契约。类型、生命周期、并发、持久化和外部边界按具体触发路径核实。

检查用户改动与无关文件未被覆盖、依赖与锁定来源一致、所有真实消费者同步、测试能观测行为、错误传播不被吞掉。重复补丁先查根因，未证明风险不要凭个人风格设阻塞。跨边界风险用 [blast-radius](../../blast-radius/SKILL.md)，需要独立审查时使用 [interrogate](../../interrogate/SKILL.md)。

## 注释与补丁约束

清理指定范围或本轮改动内的无信息注释、旁白注释与临时 workaround 时，由独立审阅或核查步骤逐项核对，禁止无差别批量删除：

- `IMPORTANT`、`do not remove`、`HACK` 等注释字样本身不是证据；用 [how](../../how/SKILL.md)／[why](../../why/SKILL.md) 或源码/提交历史核查真实约束。
- 保留法律声明、协议/契约说明与真实外部依赖或平台限制；仅删无信息废话与已被证明过期的说明。
- 本项目可修复的复杂 workaround 与错误掩盖，优先在授权范围内修根因并同步清理死路径，不把缩短注释当作修复。
- 可机械执行的约束（如“修改前需同步某处”“禁止某模式”），优先编码进类型、运行时检查、lint 或测试后再删原注释。

保留删除和保留的依据、范围与未验证项。检查不授予提交、外部评审回复或批量修复权限。
