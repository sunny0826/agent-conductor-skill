# 真实表面验证

核对实际项目启动、版本、实例归属、认证和就绪。CLI／TUI 用真实命令与终端观察；Web／Electron 用实际浏览器或应用控制；移动／原生应用用项目已有模拟器／设备驱动；API／库用真实公开入口并读回结果。宿主没有控制能力就报告未验证，不安装第三方控制技能冒充可用。

先复用项目验收技能／harness，缺可复用说明且当前任务确需时使用包内 [生成器](../../create-verification-skill/SKILL.md)。测试、编译和绿 CI 仅证明各自范围，不能代替用户等待的真实行为。

驱动前、异常后及新会话重验健康／身份；进程正常但 UI 卡住重置已知状态，不在未知实例继续。只操作本次拥有的实例，临时状态清理而证据保留并读回。验收也会产生副作用：浏览器 profile、下载、日志和辅助脚本须计入本次目录与资源边界，不能只检查正式输出而漏掉用户实际拿到的整棵目录。输入、副作用、返回和异步完成边界都要记录，不能只测成功状态码。安装、升级或发布类验证不止步于退出码与就绪翻转：核对实际生效的版本与它被期望跑通的调用链，多处声明同一版本号时逐处对账。

原型、严格只读调查和未经授权的运行不自动修改产品或生产状态。禁止外网或真实下载时，先核对测试命令、fixture 和初始化钩子的副作用，使用已有离线／loopback 入口及可用的网络隔离；测试或“只读审查”标签不构成下载授权。必须的运行诊断缺条件就标阻塞，未执行不等于通过。

经压缩、过滤或投影的命令输出在用于证据判定（哈希、归因 diff、计数）前，用原始命令复核关键值；两者不一致以原始输出为准。一次性失败在当刻保留现场：复现输入、比较对象和门禁字段；之后的通过不能回溯归因当次失败。
